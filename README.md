# Data-Science-Projects

This repository contains data science projects completed as part of a master's program at Aalto University. 

## Ai_Project_Regression

This notebook presents a pipeline for training VGG-style Convolutional Neural Networks (CNNs) to predict children's bone age from hand X-ray images. Model performance is statistically compared using bootstrapping.

The project was completed for the AI in Health Technologies course in collaboration with Juho Karhu and Niko Sommila. The dataset used for this project is from the [RSNA Bone Age competition on Kaggle](https://www.kaggle.com/datasets/kmader/rsna-bone-age/data). The dataset is mounted from Google Drive.
